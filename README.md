# TawarKan

Marketplace *tawar-menawar* for **phones & gadgets** in Indonesia.

Sellers list with an ask price. Buyers accept or counter. A simulated seller responds until **Sepakat** or walk-away. Bargain state is stored in `sessionStorage` per listing for the MVP.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- Static seed listings (ponsel, audio, tablet, wearable)

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```
